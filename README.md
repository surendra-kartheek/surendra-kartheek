## `01` — About Me

Hi, I'm **Surendra Kartheek**, a Computer Science Engineering student at **Bharath Institute of Higher Education and Research**.

I'm building my foundation as a software developer by exploring backend engineering, software quality, data analytics, and Generative AI. I enjoy taking concepts beyond theory through projects that help me understand how applications are designed, how data moves through systems, and how software can be tested and improved.

My approach is simple: understand the problem, build a practical solution, test the important details, and keep learning from the result.

- **Primary engineering direction:** Java backend development
- **Quality mindset:** Requirements, test scenarios, debugging, and regression testing
- **Data perspective:** SQL, Python, ETL, and business-focused visualization
- **AI exploration:** NLP, LLM applications, and Retrieval-Augmented Generation

## `05` — How I Build Software

My goal is to develop a repeatable engineering workflow rather than simply make an application run.

<table>
  <tbody>
    <tr>
      <td width="42"><strong>01</strong></td>
      <td><strong>Understand</strong></td>
      <td>Clarify the problem, requirements, expected behavior, and acceptance criteria.</td>
    </tr>
    <tr>
      <td><strong>02</strong></td>
      <td><strong>Design</strong></td>
      <td>Break the solution into components, define data structures, and plan API or data flow.</td>
    </tr>
    <tr>
      <td><strong>03</strong></td>
      <td><strong>Implement</strong></td>
      <td>Build in small, understandable steps with maintainability in mind.</td>
    </tr>
    <tr>
      <td><strong>04</strong></td>
      <td><strong>Validate</strong></td>
      <td>Check expected results, test important scenarios, and verify data or API responses.</td>
    </tr>
    <tr>
      <td><strong>05</strong></td>
      <td><strong>Debug</strong></td>
      <td>Reproduce issues, investigate root causes, and verify fixes with appropriate retesting.</td>
    </tr>
    <tr>
      <td><strong>06</strong></td>
      <td><strong>Improve</strong></td>
      <td>Document decisions, refine the implementation, and identify the next learning step.</td>
    </tr>
