<h2 align="center">🧪 MY SOFTWARE QUALITY MINDSET</h2>

I believe software development is not only about writing code. It also means validating requirements, checking edge cases, handling failures, and improving reliability.

My learning roadmap includes:

- **SDLC & STLC:** Understanding the software development and testing life cycles.
- **Test design:** Writing test cases from requirements and acceptance criteria.
- **Functional & regression testing:** Verifying expected behavior and preventing regressions.
- **API testing:** Validating HTTP methods, request bodies, responses, and error cases.
- **Automation:** Building practical browser automation skills with Selenium.
- **Defect management:** Documenting reproducible issues and expected versus actual results.
